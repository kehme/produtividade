⚙ Configuração de Armazenamento em Nuvem
☁️ Supabase — Banco de dados gratuito

Todos que acessarem o link do Netlify compartilharão os mesmos dados. Gratuito, requisições ilimitadas, sem limite de "gravações por mês".

Como configurar (uma vez só, feito por qualquer computador):
1. Acesse supabase.com, crie uma conta gratuita e um novo projeto
2. No projeto, abra SQL Editor e rode o script abaixo para criar a tabela:
create table logiflow_db ( id text primary key default 'main', data jsonb not null default '[]'::jsonb, updated_at timestamptz default now() ); alter table logiflow_db enable row level security; create policy "allow anon all" on logiflow_db for all to anon using (true) with check (true); 3. Vá em Project Settings → Data API e copie a Project URL
4. Vá em Project Settings → API Keys e copie a chave anon public
5. Cole os dois valores abaixo em todos os computadores da equipe e clique em Salvar & Conectar — todos passam a compartilhar o mesmo banco
